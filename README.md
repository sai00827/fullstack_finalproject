# FarmDirect

FarmDirect is a full-stack web application that helps farmers connect directly with customers to sell fresh produce.

## Features

- View fresh farm products
- Browse product images and details
- Farmer-to-customer direct marketplace concept
- Responsive user interface
- Easy navigation and product display

## Installation and Setup

### 1. Clone the repository

```bash
git clone [https://github.com/sai00827/fullstack_finalproject.git](https://github.com/sai00827/fullstack_finalproject.git)
```

### 2. Go to the frontend folder

```bash
cd fullstack_finalproject/farmdirect-frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the application

```bash
npm run dev
```

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```
